# Glossário de versionamento

- **Git:** ferramenta que guarda o histórico de um projeto. Com ela, dá para ver o que mudou de uma versão para outra.
- **GitHub:** plataforma onde podemos hospedar um repositório Git e trabalhar nele em equipe.
- **Repositório:** lugar onde ficam os arquivos do projeto e o histórico das mudanças.
- **Commit:** registro de um conjunto de mudanças. A mensagem ajuda a entender o que foi feito. Por exemplo, `Corrige o título do glossário` indica qual parte do arquivo mudou.
- **Branch:** linha de trabalho separada, onde podemos preparar uma mudança antes de colocá-la na versão principal.
- **Main:** branch principal deste projeto. É nela que reunimos as mudanças depois da revisão.
- **Merge:** ação de juntar as mudanças de uma branch com as de outra.
- **Pull Request (PR):** pedido para que alguém revise as mudanças de uma branch antes de integrá-las.

## Qual é a diferença entre Git e GitHub?

O Git registra as mudanças do projeto e pode ser usado no próprio computador. O GitHub hospeda o repositório na internet e oferece recursos para a equipe organizar tarefas e revisar mudanças.
